TCS BaNCS → Oracle FLEXCUBE Migration

Engagement
Within Gulf Bank of Kuwait tenure
Scope
Core Banking Migration Testing
Location
Kuwait City, Kuwait
Objective

Validated the migration of core banking data and behaviour from TCS BaNCS to Oracle FLEXCUBE across two levels: individual data fields and end-to-end functionality, confirming both systems agreed before cutover.

Field-Level Validation — BaNCS vs. FLEXCUBE
  • Compared individual customer, account, and transaction fields between the two systems for completeness and accuracy after migration.
  • Checked format and data-type conversion where BaNCS and FLEXCUBE stored the same field differently (dates, currency codes, identifiers).
  • Verified mandatory fields were populated in FLEXCUBE and not left blank or defaulted incorrectly.
  • Cross-checked reference and code values (product codes, branch codes, status flags) mapped correctly from source to target.
Functionality-Level Validation — BaNCS vs. FLEXCUBE
  • Executed the same account and transaction operations on both systems and compared outcomes for parity.
  • Verified balance calculations (opening, outstanding, available) matched between BaNCS and FLEXCUBE for migrated accounts.
  • Tested core banking workflows — account opening, transaction posting, closure — behaved consistently on FLEXCUBE post-migration.
  • Logged and tracked discrepancies between the two systems through to resolution and re-validation.
